# 🌍 AI Language Translation Tool

> **An interactive, web-based language translation application.**
> Developed as Task 1 for the CodeAlpha Artificial Intelligence Internship.

## 📖 Overview
This project is a lightweight, user-friendly web application designed to seamlessly bridge language barriers. Built with Python and Streamlit, it leverages reliable translation APIs to provide accurate text translation and real-time audio pronunciation across multiple global languages.

## ✨ Features
* **Multi-Language Support:** Accurately translates text across a comprehensive list of supported languages.
* **Auto-Detection:** Intelligently identifies the input text's source language to streamline the user experience.
* **Text-to-Speech (TTS) Integration:** Generates high-quality audio pronunciations of translated text for enhanced accessibility and language learning.
* **Interactive UI:** Features a clean, responsive, and intuitive interface powered by Streamlit.

## 🛠️ Technologies Used
* **Core Language:** Python
* **Frontend Framework:** Streamlit
* **Translation Engine:** `deep-translator` API
* **Audio Generation:** `gTTS` (Google Text-to-Speech)

## 🚀 Getting Started

### Prerequisites
Ensure you have [Python 3.7+](https://www.python.org/downloads/) installed on your local machine.

### Installation & Execution

**1. Clone the repository:**
```bash
git clone [https://github.com/YOUR_USERNAME/CodeAlpha_Language_Translation_Tool.git](https://github.com/YOUR_USERNAME/CodeAlpha_Language_Translation_Tool.git)
cd CodeAlpha_Language_Translation_Tool

2. Install the required dependencies:

Bash
pip install -r requirements.txt

3. Run the application:

Bash
streamlit run app.py

Note: After running the execution command, open the provided Local Network URL (typically http://localhost:8501) in your web browser to interact with the application.
